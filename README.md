# Flutter Projects

Mini proyectos y widgets construidos con Flutter para practicar desarrollo movil multiplataforma.

## Proyectos

```
/todo-app       - App de tareas con estado local
/weather-app    - App del clima consumiendo API publica
/calculator     - Calculadora con UI personalizada
```

## Requisitos

- Flutter SDK 3.x
- Dart 3.x

```bash
flutter pub get
flutter run
```
